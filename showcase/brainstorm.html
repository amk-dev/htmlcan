Feature Brainstorm

htmlcan v2 · Session with Claude

Collaborative viewing
Multiple users view the same shared canvas in real-time with cursors. Like Figma multiplayer but for HTML pages.
High effortHigh impact
Claude Code integration
Embed a chat panel that talks to Claude. "Generate a pricing page" → appears on canvas instantly. The full antidraw loop.
Medium effortHigh impact
Annotation layer
Draw arrows, add sticky notes, and leave comments on top of HTML pages. Useful for design reviews and async feedback.
Medium effortv2.1
Template gallery
Pre-built HTML templates: dashboards, reports, specs, changelogs. One-click to add to your canvas and customize.
Low effortv2.0
Version diffing
Track changes to HTML files over time. Visual diff showing what changed between saves. Git-like history for pages.
High effortv3.0
Recommendation
Start with Template gallery (quick win, low effort) and Claude Code integration (differentiator). Save multiplayer and version diffing for v3 when the user base justifies the infrastructure.
