Share API

v1.0 · api.htmlcan.com

POST /api/share

Create a new shared canvas. Uploads HTML pages and returns a shareable URL.

Request Body
pages array HTML pages required
.name string Page filename without .html
.content string HTML content
{ "id": "abc123", "url": "https://htmlcan.com/s/abc123", "expiresAt": "2026-05-17T00:00:00Z" }
GET /api/share/:id

Retrieve a shared canvas manifest with page list and metadata.

{ "id": "abc123", "pages": ["dashboard", "login", "settings"], "createdAt": "2026-05-10T12:00:00Z" }
GET /api/share/:id/pages/:name

Fetch individual HTML page content from a shared canvas.

DELETE /api/share/:id

Delete a shared canvas. Requires authentication.
